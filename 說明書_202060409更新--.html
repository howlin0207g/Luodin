  • 請勿在手部濕潤的情況下觸摸產品或連接USB線。

  • 勿自行拆卸、改裝或嘗試修理本產品。

  • 請將產品放置於兒童無法觸及的地方存放。

  • 請在不使用產品時，將其存放於乾燥且通風良好的環境。

  • 產品若因用戶自行拆卸或未經官方維修中心進行修理，即便在保修期間內，也無法享受免費保修服務。

  • 充電時請先關閉設備電源後再進行充電。

  • 前置螢幕為玻璃材質，輕微跌落或碰撞均可能造成損壞，請小心使用。

按鍵功能說明

① 【】電源鍵（ON / OFF）

長按即可開機，再次長按即可關機。

② 【】快門鍵（拍照 / 攝影）

輕按可自動對焦；當對焦框由紅色變成綠色時，長按完成拍照。

③ 【W】縮小鍵 / ④ 【T】放大鍵

按【W】可縮小畫面、按【T】可放大畫面。最大支援16倍變焦。

⑤ 【】上鍵（連拍模式 / 上移選項）

拍照模式時，開啟連拍模式（一次可連續拍攝3張照片）。

螢幕顯示清單時，可上移選項。

⑥ 【】左鍵（定時拍攝 / 下一個檔案）

拍照模式時，可依次切換2秒 / 5秒 / 10秒定時拍攝。進入相冊後，可切換瀏覽上一個檔案

⑦ 【】右鍵（閃光燈切換 / 上一個檔案）在拍照模式時，用於打開或關閉閃光燈。進入相冊後，可切換瀏覽下一個檔案

⑧ 【】下鍵（相冊 / 刪除 / 下移選項）

短按可進入相冊查看已拍攝的照片，再按一次可執行刪除。螢幕顯示清單時，可下移選項。

⑨ 【OK】確認鍵用於確認操作。

⑩ 【M】模式鍵

可在拍照模式、影片模式、設定清單之間切換。自拍模式時，按此鍵可快速進入相冊。

在相冊時，按「M」鍵可返回拍照或自拍模式。

⑪ 【DISP】螢幕切換鍵

可在前置LCD與後置LCD之間切換顯示。（僅可在自拍 / 拍照模式間切換）

2. 使用方法

  1. 長按「」鍵即可開啟設備。

  2. 本產品出廠時已插入SD卡，無需額外安裝。

  3. 開機後，螢幕會根據SD卡容量顯示可拍攝照片數量或可錄影時長。

  4. 按「M」鍵可依次切換以下模式：照片模式（默認）→錄影模式→設定模式。

    再次按下模式鍵將返回照片模式。

  5. 在設定模式下，按「」鍵、「」鍵可選擇要設定的項目，並按「OK」進入選單選擇欲設置的拍攝條件，選好後再按「OK」鍵儲存設置並返回設定模式。按「M」鍵可返回照片模式。

拍照模式（後置螢幕）

  1. 開機時即默認為拍照模式。

  2. 輕按「」鍵可啟動自動對焦功能。當畫面中的對焦框從紅色變成綠色時，表示對焦成功。此時長按「」鍵即可完成拍照。

攝影模式

  1. 開機時默認為拍照模式，按一次「M」鍵即可切換到攝影模式。

  2. 進入攝影模式後，對準拍攝畫面按下「」鍵即可開始錄影。

  3. 欲結束錄影時，再次按下「」鍵即可停止錄影。

注意

錄影模式不支援切換至前置螢幕。本相機影片格式為AVI，若直接傳至手機，可能無法正常播放。建議用戶將影片轉換為MP4格式後再播放或分享。

自拍模式（前置螢幕）

  1. 開機時默認為拍照模式，按「DISP」鍵即可切換為前置LCD自拍界面。

  2. 對準自己所需畫面後，即可自拍。

注意：切換至前置螢幕時不支援錄影功能。

瀏覽 / 刪除檔案

  1. 於拍照模式下，按「」鍵可進入相冊；自拍模式時，則按「M」鍵可快速進入相冊（但照片及顯示文字會呈現左右相反）。

  2. 使用「」鍵和「」鍵查看已拍攝的照片或影片。

  3. 再按一次「」鍵可執行刪除。

  4. 按「M」鍵可返回照片或自拍模式。

連接電腦 & 充電方式

  1. 請勿在未關機狀態下將相機透過USB線連接至電腦或電源供應器。

  2. 連接電腦後，將設備開機，設備螢幕將提供三個選項：

    ㆍ磁碟機：僅用於照片與影片傳輸； ㆍ網路攝影機：當作網路攝影機使用； ㆍ充電：僅供電，不傳輸資料。

  3. 當將相機作為儲存設備使用時，請務必保管好設備資料。

    注意：如需恢復資料或格式化記憶卡，SD卡內容可能會被刪除，請使用“電腦”方式管理文件。

  4. 充電完成時，紅色指示燈將熄滅。

    3. 常見問題(FAQ)

設備無法開機

    • 電池電量不足，請先為設備充電。


      SD卡無法插入或無法識別

    • 請確認金屬片方向正確：將相機正面朝上、金屬接觸面朝上，推入至「有卡扣聲」表示安裝完成。若未聽到提示聲，可能為插入角度不正確，請重新插入。

      螢幕卡住或操作無反應

    • 儲存空間不足或系統短暫卡頓。關閉設備後稍等再重新啟動。

    • 請用尖細物品在SD卡槽與充電接口之間的小孔長按2~3秒，以重置設備。

    • 若問題仍存在，請進行「恢復出廠」設定。

    • 若仍未改善，請聯繫客服中心處理。


      無法在手機上播放錄製影片

    • 本機錄製格式為AVI格式，部分智慧型手機不支援此格式，可能導致無聲或黑屏

      •

      解決方式：將文件轉換為MP4格式即可正常播放及分享。


      預覽畫面閃爍且出現重複的黑色橫條紋

      解答：室內或房間內的螢光燈、LED燈實際上正以極快的速度閃爍。雖然肉眼幾乎無法察覺，但當相機螢幕（LCD預覽）的刷新頻率與照明的閃爍頻率不一致時，畫面就可能出現閃爍、晃動或亮度不穩的現象。

      換句話說，因室內照明導致相機LCD畫面閃爍是正常現象，並非產品故障。這是當照明與相機以不同速度更新畫面時，自然產生的「閃爍現象 (Flicker)」。

      這種現象可能出現在相機、智慧型手機、攝影機等所有數位拍攝設備中，是僅在特定照明環境下產生的正常特性。若在陽光充足的戶外拍攝時仍出現相同現象，請聯絡LUODIN客服中心尋求協助。

      雖然設定了時間，但「秒數」對不上

    • 解答：「秒」並非由使用者直接設定的數值，而是由內部系統時間即時延續的結構。因此，即使更改了時、分，之前的秒數仍會照常延續。這並非產品錯 誤

，而是所有數位設備中皆一致適用的正常時間顯示方式。
